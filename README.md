# 📝 TaskFlow – Full Stack Task Management System

A complete Full Stack Task Management Application built using:

- ⚛️ React (Frontend)
- 🟢 Node.js + Express (Backend)
- 🗄️ MySQL (Database)
- 🔐 JWT Authentication
- 👤 Role-Based Authorization (User & Admin)

---

## 🚀 Features

### 👤 User Features
- Register & Login
- Create Tasks
- View Personal Tasks
- Update Task Status
- Delete Tasks
- Search & Filter Tasks
- Logout

### 🛡️ Admin Features
- View All Users
- View Tasks of Any User
- Delete Users
- Role-Based Access Control
- Secure Admin Dashboard
